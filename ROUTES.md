# Маршруты

Каждая страница — отдельный файл Claude Design (`original-export/project/<Имя>.dc.html`) и отдельный маршрут.
Переходы — обычные ссылки `<a href>`, с полной загрузкой страницы (как переход между артбордами в Claude Design:
у каждой страницы своё состояние, общее — только `localStorage`). Таблица маршрутов: `src/routes.ts`, `src/App.tsx`.

| Маршрут | Исходный файл | Код | Заголовок вкладки | Назначение |
|---|---|---|---|---|
| `/` | `Main.dc.html` | `src/pages/Main` | Советский пластик — мир карболитовых статуэток | Главная: карусель новостей, первый экран, 8 случайных избранных статуэток, блок «Что такое карболит?», «Новости и статьи» |
| `/catalog` | `Catalog.dc.html` | `src/pages/Catalog` | Коллекция — каталог статуэток | Каталог: поиск, фильтры по категории и тегам, сортировка, страницы по 12 карточек |
| `/figurine` | `Figurine.dc.html` | `src/pages/Figurine` | Статуэтка — карточка предмета | Карточка статуэтки: ракурсы, характеристики, теги, заметка «Хочу купить», «Другие статуэтки» |
| `/carbolite` | `Carbolite.dc.html` | `src/pages/Carbolite` | О карболите | Статья «О карболите» |
| `/articles` | `Materials.dc.html` | `src/pages/Materials` | Статьи — Советский пластик | Список статей с фильтром по типу |
| `/article` | `Article.dc.html` | `src/pages/Article` | Статья — пример материала | Пример статьи (текст, цитата, таблица) |
| `/login` | `Login.dc.html` | `src/pages/Login` | Вход и регистрация — Советский пластик | Вход и регистрация |
| `/account` | `Account.dc.html` | `src/pages/Account` | Личный кабинет — Советский пластик | Личный кабинет: «Хочу купить», «Есть в коллекции», профиль, кнопка «Админ-панель» |
| `/admin` | `Admin.dc.html` | `src/pages/Admin` | КарболитЪ — админ-панель | Админ-панель по структуре `karbolit-admin-structure.md` |
| `/_design/site-header` | `SiteHeader.dc.html` | `src/components/SiteHeader` | (Шапка сайта) | Служебная доска: шапка отдельно (на холсте Claude Design это отдельный артборд) |
| `/_design/site-footer` | `SiteFooter.dc.html` | `src/components/SiteFooter` | (Подвал сайта) | Служебная доска: подвал отдельно |
| любой другой | — | `src/NotFound.tsx` | — | Служебная заглушка «Страница не найдена» со списком маршрутов. **В оригинале её не было.** |

Точные заголовки вкладок берутся из `<title>` исходных файлов и хранятся в `src/pages/*/index.tsx` (`meta.title`).

Внутри страниц есть якоря: `/#top`, `/#collection`, `/#about`, `/#news` (главная), `#top` на странице статуэтки.

## Состояния, которые не имеют отдельного адреса

| Где | Состояние | Как открыть |
|---|---|---|
| Все страницы с карточками | Окно «Войдите в аккаунт» | Без входа нажать сердечко или галочку |
| Главная, каталог, статуэтка | Окно «Добавлено в «Хочу купить»» | После входа нажать сердечко |
| Статуэтка | Окно со всеми тегами и характеристиками | Разметка и логика окна есть, но кнопки, которая его открывает, в исходной разметке нет — окно недостижимо (так и в оригинале) |
| Шапка | Меню профиля | После входа нажать кружок аватара |
| Кабинет | Окно «Редактировать профиль» | Кнопка в кабинете или `/account?editOpen=true` |
| Админка | Разделы, карточки, вкладки, окна | Меню слева, кнопки «Изменить», «⋯», «+ Добавить…» (состояние в памяти страницы, адрес не меняется — как в оригинале) |

## Основные переходы

```
Шапка (на всех публичных страницах)
  логотип ............................ /
  «Коллекция» ........................ /catalog
  «Статьи» ........................... /articles
  «Войти» (без входа) ................ /login
  аватар → «Личный кабинет» .......... /account
  аватар → «Выйти» ................... остаётся на странице, вход сбрасывается

Подвал: логотип → /, «Коллекция» → /catalog, «Статьи» → /articles

/ (главная)
  карусель: слайды → /catalog, /article, /carbolite
  «Смотреть коллекцию», «Вся коллекция» → /catalog
  карточка статуэтки → /figurine (id статуэтки записывается в localStorage «sp-item»)
  «Подробнее о карболите» → /carbolite
  «Все статьи» → /articles; карточки новостей → /article или /catalog
  окно «Войдите в аккаунт» → /login

/catalog
  «Главная» (хлебные крошки) → /
  карточка → /figurine
  окно «Войдите в аккаунт» → /login

/figurine
  крошки → /, /catalog; тег → /catalog с этим тегом в фильтре («sp-tag»)
  «Вся коллекция» → /catalog; другая статуэтка → эта же страница с новой статуэткой (#top)

/articles → карточка → /article;   /article → «Статьи», «Все статьи» → /articles, ссылка в тексте → /catalog
/login → «Войти» / «Создать аккаунт» → /account (при ошибке переход отменяется)
/account
  «Войти» (без входа) → /login; «Перейти в коллекцию» → /catalog; карточка → /figurine
  «Админ-панель» (только у пользователя с isAdmin) → /admin
  «Выйти из аккаунта» → /

/admin
  «Открыть сайт» (меню слева, меню аватара) → /
  меню аватара → «Личный кабинет» → /account
  экран «Нет доступа» → «Войти на сайте» /login, «Личный кабинет» /account
  карточка статуэтки → «Открыть на сайте» → /figurine
```
