# Исходные файлы из Claude Design

Здесь — файлы проекта «КарболитЪ — сайт» в том виде, в каком они опубликованы в Claude Design
(артефакт `c52f9a8c-6963-4a42-9e24-f547d0ecb92b`, версия `1795007108-e29a`, 18.11.2026). Файлы не изменялись.

## project/

| Файл | Что это |
|---|---|
| `Main.dc.html` | Главная |
| `Catalog.dc.html` | Каталог |
| `Figurine.dc.html` | Страница статуэтки |
| `Carbolite.dc.html` | О карболите |
| `Materials.dc.html` | Статьи (список) |
| `Article.dc.html` | Статья (пример) |
| `Login.dc.html` | Вход и регистрация |
| `Account.dc.html` | Личный кабинет |
| `Admin.dc.html` | Админ-панель |
| `SiteHeader.dc.html`, `SiteFooter.dc.html` | Шапка и подвал (подключаются в страницы через `<dc-import>`) |
| `canvas.json` | Расположение артбордов на холсте Claude Design, порядок, стартовая страница |

Контрольные суммы SHA-256 совпадают с теми, что сервер Claude Design сообщил для опубликованной версии
(см. `SHA256SUMS`). Формат файлов — Design Components: разметка с подстановками `{{ … }}` внутри `<x-dc>`, стили в
`<helmet>`, логика в `<script type="text/x-dc">`.

Содержимое совпадает с хранилищем артефакта байт в байт (SHA-256 сверены):

## Что не вошло

- `support.js` и файлы `artifact-type/*` (среда выполнения и редактор Claude Design: `dc-runtime.js`, `app.js`,
  шрифт значков, справочные материалы) — это файлы самого типа артефакта, а не проекта. Сервер не разрешает их
  копировать. Без них `*.dc.html` не открываются как страницы в обычном браузере: для запуска используйте
  перенесённую версию в корне проекта.
- PNG `c53ab0a407170dcfa36db989bf7b0144` из хранилища артефакта: текущие страницы на него не ссылаются, сервер
  не отдаёт его для чтения.
- Шрифт Onest подключался ссылкой на Google Fonts (`https://fonts.googleapis.com/css2?family=Onest:wght@200;300;400;500;600&display=swap`),
  файлов шрифта в проекте не было.
