## Сценарии, которые прошли автоматически (скриншоты `docs/screenshots/state_*.png`)

Гость нажимает сердечко → окно «Войдите в аккаунт»; вошедший нажимает сердечко → окно «Где планирую купить»;
поиск в каталоге без результатов; вкладка регистрации; ошибка входа с пустой формой; переключение новости в карусели;
следующий ракурс на странице статуэтки; экран «Нет доступа» в админке; все 9 списков админки; карточка статуэтки и её
вкладка фотографий; ошибки при создании пустой статуэтки; меню «⋯» строки; меню аватара; админка на телефоне.

## Горизонтальная прокрутка

Проверена на всех маршрутах и ширинах. Есть только у админки на ширине 768 и 390 px (ширина страницы 909 px):
строки блока «Последние изменения» на обзоре имеют `min-width: 860px` по правилу из исходных стилей (`.a-tr` в
`@media (max-width:800px)`). Стили перенесены без изменений, поэтому, по всей видимости, так же и в оригинале — не исправлялось.

## Не проверено

- **Сравнение с рендером Claude Design.** Открыть исходные `*.dc.html` в их родной среде из этой сессии нельзя, поэтому
  скриншоты оригинала не сняты и попиксельно не сравнивались. Сравнение выполнено по исходному коду (тексты, классы,
  подписи, стили — см. выше). Локально стоит открыть артефакт в Claude Design рядом с `npm run dev` и сравнить глазами
  главную, каталог, страницу статуэтки, кабинет и админку на ширинах 1440 и 390.
- Загрузка настоящих фотографий в админке и аватара в кабинете (нужен файл с диска) — код перенесён без изменений, вручную не нажималось.
- Браузеры, кроме Chrome (Safari, Firefox).
- Работа на Windows и macOS: команды стандартные, но запускались только в Linux.

## Скриншоты

`docs/screenshots/<страница>_<ширина>.png` — страницы целиком на ширинах 1440, 768 и 390 px;
`docs/screenshots/state_<сценарий>.png` — состояния из списка выше; `report.json` — результат проверки
(заголовок вкладки, ширина страницы, ошибки консоли). Повторить: `npm run build && npm run preview`, затем
`python3 scripts/check_and_screenshots.py`.
